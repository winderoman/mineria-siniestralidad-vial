# Proyecto de Minería de Datos — Movilidad y siniestralidad vial

## Problema

¿En qué sectores viales críticos del país y bajo qué condiciones
se concentra la mayor cantidad de personas fallecidas en siniestros
viales, para que el Observatorio Nacional de Seguridad Vial de la ANSV y las secretarías de
tránsito departamentales decidan cuáles corredores intervenir primero en el próximo plan de
seguridad vial?

**Quién decide con el resultado:** el equipo del Observatorio Nacional de Seguridad Vial (ANSV),
que define la lista de corredores priorizados, y los secretarios de tránsito departamentales y
municipales, que asignan el presupuesto de señalización, control de velocidad y operativos.
